The portfolio is a static website and does not require a package installation or build step.

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/AND32148/andy-kono-portfolio.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

You can also open the folder in Visual Studio Code and use a local development server if you prefer.

## Deployment

This website is hosted with GitHub Pages from the `main` branch, using the repository root (`/`) as the publishing folder.

Live URL: https://and32148.github.io/andy-kono-portfolio/
